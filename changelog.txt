🔧 *BUG FIX*

> 🎯 *No-Prefix Command — Respons Tidak Akurat (Extra Words)*
> Command tanpa prefix merespons meski ada kata tambahan di belakangnya
> Contoh: mengetik `info dulu` atau `ping bla bla` tanpa prefix → bot merespons
> Harusnya command no-prefix hanya merespons kalau diketik *persis* tanpa kata tambahan
> Diperbaiki dengan guard `if (!m.prefix && m.query) break` di setiap command standalone
> Command yang butuh query (seperti `tanya`, `cuaca`, dll) tidak terpengaruh
> Berlaku di bot utama maupun userjadibot — handler sama (`message.js`)

> 🎌 *Animasu — URL Anime Season Ke-2/3 Selalu 404*
> Slug di URL Animasu tidak konsisten untuk season lanjutan
> Contoh: anime pakai `-s2` bukan `-season-2`, atau slug beda total
> Ditambahkan `fetchAnimeUrlFromEpisodePage()` sebagai fallback
> Fungsi ambil URL anime asli dari halaman episode langsung
> Berlaku di `cariEpisodeBaru()`, `simulasi()`, `getAiringStatus()`

> 🔁 *Animasu — Fungsi simulasi() Tidak Pakai Fallback URL*
> `simulasi()` langsung crash kalau slug anime 404
> Kini pakai fallback URL sama seperti `cariEpisodeBaru()`

> 📊 *Animasu — getAiringStatus() Diam-diam Drop Anime Season*
> Anime season ke-2/3 selalu gagal fetch dan dibuang tanpa error
> `postLink` tidak disimpan di map sehingga fallback tidak bisa jalan
> Kini `postLink` disimpan di map dan fallback aktif untuk semua entry

> 📨 *Animasu — Notifikasi Episode Sama Muncul 2 Kali*
> Animasu terkadang upload 2 post berbeda untuk 1 episode yang sama
> Kedua post punya ID berbeda sehingga lolos dedup `idTerkirim`
> Kini dedup tambahan by `animeSlug + epNum` sebelum kirim

> ⚡ *Speedtest — require is not defined di message.js*
> `message.js` pakai ES module, tidak bisa pakai `require()` langsung
> Command `.speedtest` error saat pertama dijalankan
> Diganti ke `_require()` (createRequire) sesuai pola file lain

> 🛡️ *Anti Call — Jadibot QR Tidak Bisa Tolak Panggilan*

> Jadibot QR tidak bisa tolak panggilan sama sekali
> Kini dipasang di *Pairing Code* & *QR Code*
> Berlaku untuk panggilan *suara* & *video*
> Whitelist & pesan tolak custom tetap per nomor jadibot

> 🔕 *Anti Call — Command Tidak Direspons Jadibot*
> `anticall` `ac` `anticallvid` `acv` tidak ada di whitelist
> Bot diam saja saat command dikirim ke nomor jadibot
> Semua alias sudah ditambahkan ke allowed command jadibot

> 🚧 *Anti Call — Diblock saat Kirim ke Bot Utama*
> User jadibot diblock guard saat kirim command ke bot utama
> Guard lama hanya izinkan: `jadibot` `stopbot` `listbot`
> Kini `anticall` & `anticallvid` ikut diizinkan tembus guard

> 💾 *Anti Call — Setting Tersimpan ke Tempat yang Salah*
> Setting tersimpan ke config bot utama, bukan ke jadibot
> Handler tidak bisa deteksi konteks sender jadibot
> Kini handler cek sender di `jadibotMap` secara realtime
> Setting tersimpan ke `jadibot_settings.json[nomor]` yang benar
> Tidak ada bentrok antar jadibot maupun bot utama
